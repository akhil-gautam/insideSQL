Startup now acquires a nonblocking exclusive [standard-library File lock](https://doc.rust-lang.org/std/fs/struct.File.html#method.try_lock) in the canonical private directory before credentials, initialization, logs or child launch. The descriptor stays with the exact owned Child until shutdown finishes. A competing same-process or separate-process start fails at ownership before touching the owner's connection,999.99 data, PID, credentials or log prefix. Canonical symlinks cannot bypass the guard; independent directories coexist. Explicit stop releases ownership before the old Rust object drops; that old Drop cannot stop its successor.

An older/crashed app may have a running PostgreSQL server without an application lock.
